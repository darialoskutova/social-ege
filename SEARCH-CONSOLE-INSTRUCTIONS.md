# Подключение Google Search Console

1. Откройте [Google Search Console](https://search.google.com/search-console/).
2. Нажмите «Добавить ресурс».
3. Выберите тип «Ресурс с префиксом в URL».
4. Укажите `https://darialoskutova.github.io/social-ege/`.
5. Выберите доступный способ подтверждения.
6. Если Google выдаст HTML-тег `<meta>`, вставьте его в `<head>` файла `index.html`, сразу после строки `<meta name="viewport" ...>`; затем загрузите обновлённый файл на GitHub и нажмите «Подтвердить».
7. После подтверждения откройте раздел «Файлы Sitemap» и отправьте `https://darialoskutova.github.io/social-ege/sitemap.xml`.
