# Подключение Яндекс Метрики

1. Откройте [Яндекс Метрику](https://metrica.yandex.ru/) и создайте новый счётчик.
2. В адресе сайта укажите `https://darialoskutova.github.io/social-ege/`.
3. После создания откройте настройки счётчика и скопируйте его числовой номер.
4. Откройте `analytics.js`. В первой строке замените `METRIKA_ID_HERE` на номер счётчика, сохранив кавычки:

   ```js
   const METRIKA_ID = "12345678";
   ```

5. В Метрике откройте «Настройки» → «Цели», создайте для каждого пункта цель типа «Целевое событие» и укажите без изменений:

   - `cabinet_click`
   - `program_click`
   - `program_view`
   - `about_view`
   - `materials_view`

6. В настройках счётчика включить маскирование IP, если эта возможность доступна в актуальном интерфейсе. Сейчас настройка может называться «Не сохранять полные IP-адреса посетителей сайта».
7. Загрузите изменённый `analytics.js` на GitHub и проверьте работу в режиме инкогнито: до согласия счётчик не должен запускаться.
