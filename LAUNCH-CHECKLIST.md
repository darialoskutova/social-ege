# Чек-лист запуска

- [ ] Заполнить все поля `[УКАЗАТЬ ...]` в `privacy.html`.
- [ ] Передать политику персональных данных юристу на проверку.
- [ ] Создать счётчик Яндекс Метрики для адреса сайта.
- [ ] Вставить числовой `METRIKA_ID` в `analytics.js`.
- [ ] Создать в Метрике пять целей из `METRIKA-INSTRUCTIONS.md`.
- [ ] Включить настройку, не сохраняющую полные IP-адреса, если она доступна.
- [ ] Открыть сайт в режиме инкогнито.
- [ ] Нажать «Только необходимые» и проверить отсутствие Метрики.
- [ ] Нажать «Настройки cookies», чтобы сбросить выбор.
- [ ] Нажать «Разрешить аналитику» и проверить визит в Метрике.
- [ ] Проверить клики по личному кабинету и программе.
- [ ] Проверить главную и политику на телефоне.
- [ ] Добавить сайт в Google Search Console.
- [ ] Отправить `sitemap.xml` в Search Console.
- [ ] Проверить открытие `robots.txt` и `sitemap.xml` на сайте.
