2. Что происходит сейчас

На дату этой рабочей редакции публичный сайт размещён на GitHub Pages. Собственного сервера, базы учеников и настоящей серверной авторизации у сайта нет.

  • имя, логин, черновики тестов, результаты, прогресс, сведения о работах и сообщения сохраняются только в localStorage браузера;
  • выбранный файл домашнего задания не загружается: интерфейс сохраняет только его имя;
  • GitHub как хостинг может получать технические сведения о запросах, включая IP-адрес, дату и время, браузер и запрошенный адрес;
  • Яндекс Метрика в коде не настроена и не загружается без отдельного согласия посетителя.

LocalStorage относится ко всему домену darialoskutova.github.io, поэтому текущий прототип нельзя использовать как защищённое хранилище учебных данных.

4. Субъекты, цели и правовые основания

Субъектами могут быть посетители сайта, ученики, их законные представители и плательщики по договору.

  • работа публичных страниц и обеспечение безопасности — законный интерес оператора в пределах, допускаемых законом;
  • создание кабинета, предоставление материалов, проверка тестов и ДЗ — заключение и исполнение договора;
  • операции, для которых требуется согласие, — отдельное конкретное согласие субъекта или его законного представителя;
  • аналитика и необязательные cookies — только после отдельного выбора посетителя;
  • выполнение требований законодательства — соответствующая обязанность оператора.

[ПРОВЕРИТЬ С ЮРИСТОМ] До запуска определить правовое основание для каждой цели и возрастной сценарий ученика. Согласие не должно подменять договорное основание там, где обработка объективно нужна для исполнения договора.

5. Действия с данными и способы обработки

Предполагаемые действия: сбор, запись, систематизация, накопление, хранение, уточнение, извлечение, использование, предоставление уполномоченным обработчикам, блокирование, удаление и уничтожение. Обработка смешанная, преимущественно автоматизированная.

Оператор не принимает решений, порождающих юридические последствия для ученика, исключительно на основании автоматической обработки результатов учебных тестов.

6. Место хранения и обработчики

База учётных записей, учебные данные, сообщения, файлы ДЗ и резервные копии граждан РФ должны размещаться в дата-центрах на территории России. Конкретный российский провайдер: [УКАЗАТЬ ПОСЛЕ ВЫБОРА].

До поручения обработки провайдеру необходимо проверить договор, локацию каждого сервиса, условия конфиденциальности, возврата и удаления данных, резервного копирования и уведомления об инцидентах.

Публичные страницы могут временно оставаться на GitHub Pages, однако персональные данные кабинета не должны храниться в GitHub или публичном репозитории. Использование иностранного хостинга и иных зарубежных сервисов отдельно оценивается на предмет трансграничной передачи.

7. Cookies, localStorage и аналитика

Необходимые технологии используются для выбранной темы, защищённой сессии и сохранения решения по аналитике. Сессионная cookie рабочей версии должна быть HttpOnly, Secure и SameSite; пароль и токен сессии не сохраняются в localStorage.

Яндекс Метрика может быть включена только после отдельного согласия. В Метрику не должны передаваться имя, логин, ответы, результаты, тексты сообщений, содержимое ДЗ и адреса страниц с идентификаторами ученика. Вебвизор в текущем коде выключен.

9. Несовершеннолетние

Свободная регистрация не предусматривается: аккаунты создаёт преподаватель. До создания аккаунта несовершеннолетнего оператор определяет, кто заключает договор и кто вправе дать требуемые согласия.

Для законного представителя подготовлен отдельный шаблон. Не следует собирать паспортные данные родителя или ребёнка автоматически: объём подтверждения полномочий определяется после юридической проверки.

[ПРОВЕРИТЬ С ЮРИСТОМ] Возрастные сценарии, порядок акцепта оферты, согласие законного представителя и способ проверки его полномочий.

10. Защита данных

Для рабочей версии предусматриваются разграничение student/admin на сервере, хеширование паролей Argon2id, защищённые cookie-сессии, ограничение попыток входа, приватное файловое хранилище, проверка загрузок, резервные копии, журналирование административных действий, обновления и проверка восстановления.

Ссылки на материалы и ДЗ должны выдаваться только после серверной проверки права конкретного пользователя. Секреты и ключи ответов не размещаются во frontend и публичном GitHub.

После подтверждения запроса удаляются активные сессии, учётная запись, учебные записи и файлы, если отсутствует иное законное основание хранения. Срок исполнения и исключения: [УТОЧНИТЬ ПЕРЕД ПУБЛИКАЦИЕЙ].
