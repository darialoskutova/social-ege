2. Какие данные могут обрабатываться

  • технические сведения о запросе к сайту, которые может получать хостинг GitHub Pages: IP-адрес, дата и время запроса, тип браузера и устройства, адрес запрошенной страницы;
  • данные аналитики Яндекс Метрики — только после отдельного согласия посетителя;
  • выбор темы оформления, согласие или отказ от аналитики, учебный прогресс, имя и логин кабинета — локально в браузере пользователя.

На текущем этапе у сайта нет собственного сервера и базы пользователей. Данные, сохранённые учебной частью в localStorage, остаются на устройстве пользователя и сами по себе не отправляются оператору сайта.

3. Для чего нужны данные

  • для технической загрузки и корректной работы сайта;
  • для сохранения выбранной темы, состояния учебных форм и прогресса на устройстве;
  • для получения обезличенной статистики посещений и использования публичных разделов — только при разрешённой аналитике;
  • для обнаружения технических ошибок и улучшения структуры сайта.

В цели аналитики не передаются имя, фамилия, логин, пароль, контакты, содержимое форм и ответы ученика.

4. Cookies и localStorage

Сайт использует localStorage для работы интерфейса: например, чтобы запомнить тему оформления, состояние учебных заданий и выбор посетителя по аналитике.

При выборе «Разрешить аналитику» загружается Яндекс Метрика, которая может сохранять собственные cookies и иные технические идентификаторы. При выборе «Только необходимые» Метрика не загружается.

Изменить решение можно кнопкой «Настройки cookies» ниже. После сброса сайт снова покажет выбор. Также данные сайта можно удалить в настройках браузера.

5. Сторонние сервисы

GitHub Pages

Сайт размещён на GitHub Pages. При открытии страниц GitHub может обрабатывать технические сведения в соответствии со своей политикой конфиденциальности.

Яндекс Метрика

После согласия посетителя применяется сервис веб-аналитики Яндекс Метрика. Описание используемых сервисом данных и cookies приведено в справке Метрики и справке о cookies. Правила Яндекса описаны в его политике конфиденциальности.

6. Сроки и безопасность

Выбор аналитики хранится в браузере до его сброса пользователем. Остальные локальные данные сохраняются до удаления через интерфейс сайта или настройки браузера. Сроки хранения технических данных сторонними сервисами определяются их правилами.

Оператор применяет разумные организационные и технические меры, но передача данных через интернет не может гарантировать абсолютную безопасность.

7. Права пользователя

Пользователь может запросить сведения об обработке своих данных, их уточнение, прекращение обработки или удаление в случаях, предусмотренных законом, а также отозвать согласие на аналитику.

Обращения направляются на [УКАЗАТЬ EMAIL]. Чтобы обращение можно было проверить, укажите, каким разделом сайта вы пользовались и суть запроса; не отправляйте пароль.

8. Изменения политики

Политика может обновляться при изменении сайта, используемых сервисов или требований законодательства. Актуальная версия размещается на этой странице.
